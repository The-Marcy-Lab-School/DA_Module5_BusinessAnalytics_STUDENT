# About the starter dashboards

There are 4 files here, one per domain in `../SCENARIOS.md`:

- `finance_insurance_dashboard.xlsx`
- `professional_services_dashboard.xlsx`
- `healthcare_operations_dashboard.xlsx`
- `public_sector_dashboard.xlsx`

**Pick one, delete the other 3.** Each file has the same shape:

1. **Dashboard** (empty) — where your real work goes: 3 KPI cards (North
   Star, Leading, Lagging), at least 2 charts, one interactive control
   (the "as of month" dropdown), and at least one XLOOKUP/VLOOKUP. See
   `kpi_definitions.md` for what to define **before** you build any of
   this.
2. **Raw data sheet(s)** — real transactional data, already formatted as
   Excel Tables so your formulas/charts can source from them cleanly.
3. **A reference/lookup sheet** — what your required XLOOKUP/VLOOKUP
   joins against.

Nothing on the "Dashboard" sheet is given — no card, no chart, no
dropdown, no formula. That's the actual project. `misleading_chart_example.xlsx`
is a small, separate given file for the AI exercise
(`ai_dashboard_review.md`) — not part of your own dashboard.
